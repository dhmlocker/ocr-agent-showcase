把合同 PDF 变成可分析、可问答的工作台

OCR Agent（合同智能处理系统）是一款运行在本机的合同处理桌面应用： 导入合同 PDF，完成解析与 OCR 识别、关键信息提取，再用 Agent 智能问答直接回答合同问题—— 每个答案都附带原文证据，点击即可在原文中定位。

使用流程

四步完成一次合同处理

每一步都有真实进度与执行记录，运行中可随时取消。

导入合同

选择本地 PDF 文件，系统校验文件有效性并建立内容寻址的只读档案。

解析识别

原生页直接提取、扫描页 OCR 识别；识别文本与原文页码双向联动，整行可点击定位。

合同分析

规则或大模型模式提取合同要素，按基础信息 / 付款安排 / 条款语义分组，附证据与页码。

Agent 问答

用自然语言提问，Agent 检索文档、组织证据后作答，点击证据即可回到原文核对。

识别与定位

识别文本与原文，双向联动

解析结果按页渲染成可读文本，与中央 PDF 页码双向同步；识别内容整行可点击，直接在原文中定位并高亮。

  • 原生文字层直接提取，扫描件云端 OCR（逐次授权后识别）
  • 识别文本整行可点击，PDF 高亮对应原文区域
  • 坐标经核实才用于高亮；不可信时仅跳页并如实提示
  • 表格结构化还原，支持单元格级定位
  • 解析质量门拦截乱码文字层，混合 PDF 按页路由

了解文档识别与解析

Agent 智能问答

答案后面，永远跟着证据

输入「尾款什么时候支付？」这样的自然语言问题，Agent 会检索条款、组织上下文再作答——而不是把整份文档丢给模型自由发挥。

  • 9 个白名单工具：全文检索、条款上下文、字段预览、规则问答等
  • 多轮决策循环：默认最多 10 轮、240 秒预算、连续失败自动熔断
  • 证据必须逐字摘自原文并附页码，落库前再次程序化核验
  • 答案显示依据状态与置信度；证据核验通过数一目了然
  • 点击「查看原文」直接跳转 PDF 高亮，答案页保留不动
