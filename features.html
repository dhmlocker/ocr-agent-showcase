产品功能

以下功能均以 OCR Agent V1.0 内部测试版的实际交付为准——已实现的能力如实列出， 未包含的能力也在页面底部如实说明。

01

文档管理

合同是敏感文件。文档管理的设计原则是：原件只读、内容寻址、任务可追溯—— 导入的合同永远不会被原地修改，每一次处理都留下可复查的记录。

  • 导入校验 PDF 文件头校验、200MB 大小上限、加密 PDF 明确拒绝并说明原因。
  • 内容寻址存储 按 SHA-256 指纹存储，同一文件自动去重；原件只读保存，解析与分析均基于副本产物。
  • 统一工作台 左侧导航管理文档列表与任务记录，可折叠为窄条；中央 PDF 预览始终可见。
  • PDF 预览 翻页、适合整页 / 适合宽度 / 50%–200% 手动缩放，高分屏自动适配。
  • 任务管理 每个任务记录类型、状态、真实耗时与执行事件流；底部抽屉可展开解析摘要与高级详情。
  • 运行控制 运行中可随时取消，取消真实中断后台模型请求并释放资源，而非仅改状态。
02

文档识别与解析

合同 PDF 的形态千差万别：原生文字层、扫描件、两种混杂、甚至带「伪文字层」的乱码页。 解析层按页分类路由，并用统一中间表示（Document IR）承接所有引擎的输出。

  • 原生文字层提取 直接按块提取文本并区分标题 / 段落 / 列表，保留精确坐标。
  • 页面分类 + 质量门 有效字符占比不足的「伪文字层」页面自动转入 OCR 路径，避免乱码进入检索与分析。
  • 混合型 PDF 按页路由 同一文件内原生页与扫描页分别处理，互不影响。
  • 云端 OCR（逐次授权） DeepSeek-OCR 逐页识别（含 grounding 坐标）；MinerU 整本版面解析（表格结构化、断点续查）。
  • 表格结构化 行列自洽性校验；不一致时如实标记 partial 并保留文字，绝不补写内容。
  • 坐标可信核实 OCR 坐标经核实才用于高亮定位；不可信时仅跳页并明确提示，不伪造高亮。
  • 整行点击定位 识别文本整行可点击，直接在 PDF 中定位并高亮原文区域。
本地 OCR（PaddleOCR 外部脚本） Tesseract 备选 DeepSeek-OCR 云端 MinerU 云端 跨页条款合并
打包版说明（如实）：发布版为控制体积未内置本地 OCR 运行环境，扫描件 OCR 走云端授权路径； 原生文字层 PDF 的解析不受影响。开发环境可配置本地 PaddleOCR 实现完全离线的扫描件识别。
03

全文检索

解析完成即自动建立全文索引，检索是合同分析与 Agent 问答的基础能力—— Agent 的每一次条款查找、规则问答的每一次命中，都由这条检索链路支撑。

  • SQLite FTS5 索引 解析产物按节点入库，支持 BM25 相关度排序，结果带页码与原文片段。
  • 中文检索方案 中文字级索引 + 短语匹配（如实说明：非语义分词模型），支持条款编号（「第六条」「6.1」）、中英文混排与短词。
  • 页内定位 命中结果附带页内归一化坐标（坐标可信时），可直接高亮到命中位置。
  • 开放方式 Agent「全文检索」工具、规则问答引擎与本地 API 均可调用；检索范围严格按文档与解析运行隔离。
如实说明：V1.0 界面暂未提供独立的检索面板，检索能力当前通过 Agent 问答、 规则问答与 API 使用。独立检索入口已列入后续计划（见产品现状）。
04

合同分析

合同分析回答三个问题：这份合同的甲乙双方、金额、日期是什么？付款怎么安排？关键条款说了什么？ 所有结论按「基础信息 / 付款安排 / 条款语义」分组，附原文证据与页码。

  • 双模式分析 快速 = 本地规则（12 组字段 + 18 类当事人角色，零网络零费用）；深度 = 大模型语义增强（当事人 / 合同金额 / 逐笔付款安排 / 条款义务，需授权）。
  • 结论分流 原文支持 / 存在冲突 / 无法确认 / 未找到——冲突时不擅自选值，无法确认的字段如实标注。
  • 证据程序化校验 证据必须来自本次解析、页码一致、引文逐字命中原文；校验不通过的结论不予展示。
  • 交叉核验 比例 × 基数换算核对、币种一致性、起止日期顺序等结构化校验。
  • 付款安排表格 期次 / 比例·金额 / 支付条件 / 依据四列呈现，每条结论附原文页码。
  • 结果导出 一键导出 JSON / Markdown；支持人工复核记录。
仅规则模式（离线） 大模型增强（授权后） 失败自动回退规则 文档内指令注入只记录不执行
如实说明：中文大写金额与数字金额的自动数值比对尚未实现（当前通过数字金额同值合并 与冲突标记、比例换算校验兜底）；合同分析不承诺字段 100% 抽全，以「如实标注 + 证据可核」为第一优先级。
05

Agent 智能问答

Agent 的目标不是「看起来很聪明」，而是给出有据可查的回答： 它通过多轮工具调用检索文档、组织证据，答案中的每条证据都可点击回溯到原文。

  • 9 个白名单工具 文档信息、结构摘要、全文检索、条款上下文、字段预览、规则问答、结论读取、本地解析、提交答案。
  • 多轮决策循环 默认最多 10 轮、240 秒时间预算、连续失败自动熔断；每轮工具结果回传驱动下一步决策。
  • 强制基于文档 证据必须逐字摘自工具返回的原文并附位置；证据不足时如实降低置信度，不编造。
  • 证据落库核验 回答落库前再次程序化校验；高置信度却无通过证据的回答会被降级标记。
  • 安全约束 工具参数校验、单工具调用上限、重复调用拦截；Agent 无法触发云端解析。
  • 可控成本 运行前展示服务商、模型与调用上限并需授权；取消立即中断模型请求。
工具白名单 证据逐字核验 置信度分流 无法回答如实告知 人工复核记录
06

模型与引擎配置

配置中心分两大类别：文档识别与解析（按引擎分别配置）与智能理解模型（合同分析与 Agent 问答共用）。 不配置任何模型也能使用解析、检索与规则分析。

  • 三种模型来源 本机 Ollama（自动发现模型）/ 远程 Ollama（可选 Bearer 认证）/ 云端 OpenAI 兼容接口（服务地址 + 模型 + API Key）。
  • 测试连接 Ollama 检查连通性与模型能力；云端发送一条极小请求验证配置（几乎不产生费用）。
  • 发现模型 只读获取模型列表，绝不下载；不支持模型发现的云端服务会明确提示手动填写。
  • 检测工具调用 真实发送带工具定义的探测请求——「普通文本生成成功」不等于兼容工具调用；不兼容的模型保存前会二次确认。
  • 解析引擎配置 DeepSeek-OCR（服务地址 / 模型 / API Key）、MinerU（Token / 表格开关）、本地 PaddleOCR（外部 Python 路径），测试连接按引擎适配。
  • 密钥安全 API Key 存入 Windows 凭据管理器，配置文件只保存引用名，不落明文、不进日志。
07

安全与隐私设计

面向合同场景，「数据不出本机」是默认假设，云端能力是明确授权后的例外。

  • 本地优先 解析、规则分析、检索、问答规则引擎全程零网络可用。
  • 云端逐次授权 每次外发前弹窗展示服务商、端点、上传范围与页数；拒绝即零网络请求。
  • 双重闸门 授权在 API 提交与 Worker 执行两道关卡分别校验，缺失或无效一律拒绝（fail-closed）。
  • 凭据安全 API Key 仅存 Windows 凭据管理器；本地 API 只监听 127.0.0.1，访问令牌每次启动随机生成且不落盘。
  • 进程安全 关闭窗口后 API / Worker 协作式退出，父进程看门狗防止孤儿进程残留。
以下能力 V1.0 暂未包含（如实说明）： 双文档比较功能（后续规划）；独立的全文检索界面入口（检索能力经 Agent / 问答 / API 使用）； 中文大写金额与数字金额的自动数值比对；发布版内置本地 OCR 运行环境。 详见产品现状。
