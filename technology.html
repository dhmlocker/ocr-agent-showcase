技术与产品特点

只讲在产品里真正发挥作用的技术：每一项工程选择，都对应一个合同处理场景下的真实问题。

总体架构

三进程桌面架构：界面永远不卡，任务永远可查

桌面界面、本地 API 与任务执行器运行在三个独立进程——耗时任务不阻塞界面，随机端口与访问令牌保证本地服务不对外暴露。

三进程桌面架构

PySide6 界面、FastAPI 本地服务、任务 Worker 三个进程协同：界面每秒轮询刷新而不冻结； SQLite WAL 任务队列原子领取任务；取消语义区分「排队 / 运行中 / 已结束」，完成与取消竞争时一律按取消收尾。 关闭窗口按「协作式停止 → 有限等待 → 可控终止」退出，看门狗兜底防止孤儿进程。

界面不卡顿任务可取消无残留进程

文档解析与统一中间表示（Document IR）

所有解析引擎（本地提取、云端 OCR）的输出统一为 Document IR：页面 / 节点 / 来源 / 表格四层结构， 带交叉校验规则（坐标合法、页码一致、表格不重叠）。跨页条款自动合并、解析质量门拦截乱码文字层、 坐标经核实才进入定位体系——下游的分析、检索、Agent 都建立在同一份可信数据上。

按页分类路由跨页合并交叉校验

大模型接入适配层

ProviderAdapter 注册表统一封装本机 Ollama、远程 Ollama 与云端 OpenAI 兼容接口： 模型发现、连接测试、工具调用能力探测走同一条协议实现（测试与业务共用，避免两套逻辑漂移）； 地址规范化、认证头、错误码体系（401 / 429 / 超时 / 网络异常）集中处理。 新增一种模型协议，只需注册一个适配器，不改调用方。

统一协议入口能力探测密钥入系统凭据管理器

Agent 工具调用机制

Agent 以状态图（LangGraph）编排「决策 → 执行 → 反馈」循环，最多 10 轮、240 秒预算、连续失败熔断。 工具全部白名单注册：参数 schema 校验、单工具调用上限、相同参数重复调用拦截； 工具结果以原文回传驱动下一轮决策，取消信号贯穿到模型请求内部——点「取消」是真的停。

白名单工具真实可取消成本有上限

检索与证据定位

SQLite FTS5 中文字级索引支撑全文检索；证据链三级精度——块级精确（exact）、区域（block）、仅页级（page_only）。 每条证据都要通过程序化校验：同一次解析运行、页码一致、引文逐字命中； 校验不过的证据不展示、不入库，坐标不可信时如实降级为「仅页码定位」，绝不伪造高亮。

逐字核验诚实降级单元格级定位

本地与云端模型协同

本地路径（解析、规则分析、规则问答）零网络可用；云端能力（视觉 OCR、大模型）默认关闭、逐次授权、 双闸校验（API 提交 + Worker 执行）。大模型调用全部带预算上限与超时控制，失败自动回退规则结果并如实标注模式 （仅规则 / 大模型部分完成 / 大模型失败）。开发与发布版数据目录完全隔离。

零网络可用fail-closed 授权失败自动回退
