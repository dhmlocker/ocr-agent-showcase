如实说明

已知能力边界

为了让审核方与使用者建立准确预期，以下是 V1.0 明确未包含或未完成的部分。

  • 双文档比较 V1.0 未包含该功能（后续规划中）；当前版本聚焦单份合同的完整处理链路。
  • 独立检索界面 全文检索能力已实现（FTS5 索引 + API + Agent 工具 + 规则问答），但界面暂无独立检索面板。
  • 大写金额比对 中文大写金额与数字金额的自动数值换算比对尚未实现；已有数字金额同值合并、冲突标记与比例换算校验。
  • 发布版本地 OCR 发布版未内置本地 OCR 运行环境，扫描件 OCR 走云端授权路径；开发环境支持本地 PaddleOCR。
  • 自定义视觉引擎 配置中心已支持添加与测试 OpenAI 兼容视觉引擎（实验特性），解析执行链路的接入仍在开发中。
  • 工具调用探测边界 Agent 采用文本决策协议而非原生 function-calling；「检测工具调用」结果为模型选型期提示，运行时无自动降级。
  • 模型效果依赖实测 不同模型的识别质量、抽取准确率与响应速度差异需以实测为准，当前尚未发布任何准确率承诺。
